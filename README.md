# TabiLog
TabiLog is a travel planner and a journal for Japan. Where you can pick from each prefecture in Japan and plan trips where you want to go. 
A trip can also be documented after with thoughts and fun events that took place and if you wanna go there again. Maybe have picture options to see and remember more of the trip.

It will work with an svg map where you click the prefecture, then get a side menu where you can see added trips, or have an option to add a new trip. You will also be able to go into an existing trip and see what it was like or to edit it.

A trip will have statuses like Planned, Visited, Want to go again. to easier track where one have been and what was nice.

For each prefecture there will also be cities to pick from for a planned trip and user can enter all information needed, maybe even planned dates of going there.
